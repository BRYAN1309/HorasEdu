🎓 HorasEdu – Digital Learning Platform for Batak Culture

HorasEdu is a web-based Learning Management System (LMS) built to preserve and promote Batak culture and language through an interactive, modern, and fun learning experience.
The platform combines educational content, gamified learning, and chatbot assistance to make cultural learning accessible and engaging in the digital era. 🌏

🚀 Features
📘 Interactive Learning Modules — Learn Batak language from basic to advanced levels.
🧠 Quizzes & Final Exams — Evaluate progress with interactive assessments.
🎮 Mini-Games — Engage with Batak culture through fun activities like:
Memory Cards
Speed Typing
Drag & Match
💬 Chatbot Integration — Get real-time guidance and cultural insights during the learning journey.
📊 User Progress Tracking — Save quiz scores, track module completion, and revisit past lessons easily.

🌍 Why We Built It
Batak culture and language are fading among the younger generation. HorasEdu was created to revitalize cultural learning by transforming traditional education into an interactive digital experience.
Through technology, we aim to make learning Batak fun, accessible, and relevant to modern learners — preserving cultural identity in the digital age.
